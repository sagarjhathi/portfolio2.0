Personal Project

Amazon Automation Framework

One problem, two stacks. This end-to-end suite verifies that Amazon search filters return results that truly match the selected criteria. I built it with Java and Selenium first, then rebuilt it with Playwright and TypeScript to compare the two approaches. Pick one to open its repository.
